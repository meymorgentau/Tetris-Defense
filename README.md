# 🎮 TETRIS-DEFENSE — Тетрис-Защита

Аркадная игра на Python и Pygame: управление пушкой, стрельба по падающим фигурам и очистка игрового поля.

**Суть игры:** игрок управляет пушкой в нижней части экрана и уничтожает кубики падающих фигур. Попадание пули удаляет один кубик, а полностью уничтоженная фигура исчезает. Оставшиеся кубики закрепляются на поле. Полностью заполненные горизонтальные линии удаляются. Цель — набрать как можно больше очков и не допустить переполнения игрового поля.

## Структура проекта

```text
Tetris-Defense/
├── Tetris_Defense.py   # Главный файл: игровой цикл, события и логика игры
├── constants.py        # Константы: размеры окна, игрового поля и цвета
├── field.py            # Игровое поле: матрица, закрепление кубиков, очистка линий
├── block.py            # Падающие фигуры: создание, движение и разрушение кубиков
├── bullet.py           # Пули: движение, столкновения и отрисовка
├── player.py           # Пушка: управление и позиция выстрела
├── ui.py               # Интерфейс: счёт, количество линий и экран проигрыша
├── game.py             # Дополнительный модуль игровой логики
├── .gitignore          # Файлы и каталоги, исключённые из Git
├── .gitattributes      # Настройки обработки файлов в Git
└── README.md           # Описание проекта и инструкция по запуску
```

Игровое окно имеет размер 800 × 600 пикселей. Игровое поле представлено матрицей 10 × 20 ячеек. Справа находится панель интерфейса с текущим счётом, количеством очищенных линий и подсказками по управлению.

**Tetris_Defense.py** — основной модуль, объединяющий остальные компоненты. Он обрабатывает пользовательский ввод, обновляет состояние игры, проверяет столкновения и выполняет отрисовку.

**block.py** отвечает за падающие фигуры, состоящие из отдельных кубиков. При попадании пули один кубик удаляется из структуры фигуры. Если кубиков не осталось, фигура уничтожается полностью.

**field.py** хранит закреплённые кубики в матрице игрового поля. Когда фигура больше не может опускаться, её оставшиеся кубики фиксируются. После этого проверяются полностью заполненные горизонтальные линии: они удаляются, а расположенные выше элементы смещаются вниз.

**player.py** реализует управление пушкой с помощью стрелок влево и вправо. **bullet.py** отвечает за движение пуль вверх и их взаимодействие с падающими фигурами.

С ростом счёта игра постепенно усложняется: скорость падения фигур увеличивается, а интервал между появлением новых фигур уменьшается. Если для новой фигуры не удаётся найти подходящее место, игра завершается. После проигрыша можно начать заново.

## Быстрый старт

### Игра

Необходим Python 3.12 и библиотека Pygame 2.6.1.

```bash
git clone https://github.com/meymorgentau/Tetris-Defense.git
cd Tetris-Defense

python -m venv .venv
.venv\Scripts\activate

python -m pip install pygame==2.6.1
python Tetris_Defense.py
```

После запуска откроется игровое окно размером 800 × 600 пикселей.

Управление: `←`/`→` — перемещение пушки, `Space` — выстрел, `R` — перезапуск после проигрыша.

### Игровая механика

- **Падение фигур:** фигуры автоматически опускаются сверху вниз с заданным интервалом.
- **Стрельба:** пули движутся вверх и уничтожают отдельные кубики при попадании.
- **Закрепление:** кубики фиксируются на поле, когда фигура больше не может двигаться вниз.
- **Очистка линий:** заполненные горизонтальные линии удаляются, освобождая место.
- **Начисление очков:** за уничтожение кубиков, полное уничтожение фигур и очистку линий начисляются очки.
- **Увеличение сложности:** с ростом счёта фигуры падают быстрее и появляются чаще.
