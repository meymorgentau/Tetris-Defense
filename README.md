# 🎮 TETRIS-DEFENSE — Тетрис-Защита

Аркадная игра на Python и Pygame: управление пушкой, стрельба по падающим фигурам и очистка игрового поля.

**Суть игры:** игрок управляет пушкой в нижней части экрана и уничтожает кубики падающих фигур. Попадание пули удаляет один кубик, а полностью уничтоженная фигура исчезает. Оставшиеся кубики закрепляются на поле. Полностью заполненные горизонтальные линии удаляются. Цель — набрать как можно больше очков и не допустить переполнения игрового поля.

## Структура проекта

```text
Tetris-Defense/
├── Tetris_Defense.py   # Главный файл: игровой цикл, события и логика игры
├── constants.py        # Константы: размеры окна, игрового поля и цвета
├── field.py            # Игровое поле, закрепление кубиков и очистка линий
├── block.py            # Создание, движение и разрушение падающих фигур
├── bullet.py           # Пули: движение, столкновения и отрисовка
├── player.py           # Пушка: управление и позиция выстрела
├── ui.py               # Интерфейс, счёт и экран проигрыша
├── game.py             # Дополнительный модуль игровой логики
├── shapes.cfg          # Текстовые маски геометрии фигур
├── shapes_loader.py    # Загрузка и проверка масок фигур
├── defense_logger.py   # Настройка журналирования игровых событий
├── defense.log         # Журнал уничтоженных линий
├── .gitignore          # Файлы и каталоги, исключённые из Git
├── .gitattributes      # Настройки обработки файлов в Git
└── README.md           # Описание проекта и инструкция по запуску
```

Игровое окно имеет размер 800 × 600 пикселей. Игровое поле представлено матрицей 10 × 20 ячеек. Справа находится панель интерфейса с текущим счётом, количеством очищенных линий и подсказками по управлению.

**Tetris_Defense.py** — основной модуль, объединяющий компоненты игры. Он обрабатывает пользовательский ввод, обновляет состояние игры, проверяет столкновения, создаёт новые фигуры и выполняет отрисовку.

**block.py** отвечает за падающие фигуры, состоящие из отдельных кубиков. Геометрия фигур загружается из внешнего файла `shapes.cfg`, поэтому шаблоны фигур можно изменять без редактирования самого класса `FallingBlock`. При попадании пули один кубик удаляется из структуры фигуры. Если кубиков не осталось, фигура уничтожается полностью.

**shapes.cfg** содержит текстовые маски фигур. Каждая фигура обозначается именем в квадратных скобках, после которого указываются строки маски. Символ `1` обозначает наличие кубика, а `0` — пустую ячейку. Например:

```text
[T]
111
010

[Square]
11
11
```

В файле предусмотрены маски фигур разных форм и размеров. Пустые строки и строки, начинающиеся с `#`, используются для разделения фигур и комментариев.

**shapes_loader.py** реализует загрузку конфигурации при запуске игры. Парсер последовательно считывает строки файла, определяет названия фигур, проверяет корректность масок и преобразует их в списки координат кубиков. Проверяется наличие имени и маски, одинаковая длина строк, допустимость символов `0` и `1`, отсутствие пустых фигур и повторяющихся имён. При обнаружении некорректной структуры возникает ошибка с описанием проблемы.

**field.py** хранит закреплённые кубики в матрице игрового поля. Когда фигура больше не может опускаться, её оставшиеся кубики фиксируются. После этого проверяются полностью заполненные горизонтальные линии: они удаляются, а свободные строки добавляются сверху. Метод очистки возвращает количество удалённых линий и индексы строк, которые были заполнены до очистки.

**defense_logger.py** отвечает за журналирование событий очистки линий. Для записи используется стандартный модуль `logging`. При удалении каждой заполненной линии в журнал заносится дата, время и индекс строки.

**defense.log** хранит записи о событиях очистки линий. Новые записи добавляются в конец файла, поэтому предыдущая история сохраняется между запусками игры.

**player.py** реализует управление пушкой с помощью стрелок влево и вправо. **bullet.py** отвечает за движение пуль вверх и их взаимодействие с падающими фигурами.

С ростом счёта игра постепенно усложняется: скорость падения фигур увеличивается, а интервал между появлением новых фигур уменьшается. Если для новой фигуры не удаётся найти подходящее место, игра завершается. После проигрыша можно начать заново.

## Быстрый старт

### Требования

Для запуска необходимы:
- Python 3.12;
- Pygame 2.6.1.

### Установка и запуск

```bash
git clone https://github.com/meymorgentau/Tetris-Defense.git
cd Tetris-Defense

python -m venv .venv
.venv\Scripts\activate

python -m pip install pygame==2.6.1
python Tetris_Defense.py
```

Перед запуском необходимо убедиться, что файлы `shapes.cfg` и `shapes_loader.py` находятся в папке проекта вместе с остальными модулями. При отсутствии или некорректном содержимом конфигурационного файла загрузчик сообщает об ошибке.

После запуска откроется игровое окно размером 800 × 600 пикселей.

**Управление:**
- `←` / `→` — перемещение пушки;
- `Space` — выстрел;
- `R` — перезапуск после проигрыша.

## Игровая механика

- **Падение фигур:** фигуры автоматически опускаются сверху вниз с заданным интервалом.
- **Стрельба:** пули движутся вверх и уничтожают отдельные кубики при попадании.
- **Закрепление:** кубики фиксируются на поле, когда фигура больше не может двигаться вниз.
- **Очистка линий:** заполненные горизонтальные линии удаляются, освобождая место.
- **Начисление очков:** за уничтожение кубиков, полное уничтожение фигур и очистку линий начисляются очки.
- **Увеличение сложности:** с ростом счёта фигуры падают быстрее и появляются чаще.
- **Внешняя конфигурация:** геометрия фигур хранится в `shapes.cfg` и загружается при старте игры.
- **Проверка конфигурации:** парсер проверяет структуру масок и сообщает об обнаруженных ошибках.
- **Журналирование:** информация об уничтоженных линиях записывается в `defense.log` с указанием времени и индекса строки.
