# 🎮 TETRIS-DEFENSE — Тетрис-Защита

Аркадная игра на Python и Pygame: управление пушкой, стрельба по падающим фигурам и очистка игрового поля. Проект постепенно расширялся в рамках пяти лабораторных работ: от разработки игровой механики до создания Telegram-бота, переноса логики на JavaScript и разработки браузерной версии игры.

Суть игры: игрок управляет пушкой в нижней части экрана и уничтожает кубики падающих фигур. Попадание пули удаляет один кубик, а полностью уничтоженная фигура исчезает. Оставшиеся кубики закрепляются на поле. Полностью заполненные горизонтальные линии удаляются. Цель — набрать как можно больше очков и не допустить переполнения игрового поля.

## Лабораторная работа №1 — Разработка игры на Python и Pygame

Первая лабораторная работа посвящена созданию игры «Тетрис-Защита» с использованием языка Python и библиотеки Pygame.

Игровое окно имеет размер 800 × 600 пикселей. Игровое поле представлено матрицей 10 × 20 ячеек. Справа находится панель интерфейса с текущим счётом, количеством очищенных линий и подсказками по управлению.

`Tetris_Defense.py` — основной модуль, объединяющий компоненты игры. Он обрабатывает пользовательский ввод, обновляет состояние игры, проверяет столкновения, создаёт новые фигуры и выполняет отрисовку.

`block.py` отвечает за падающие фигуры, состоящие из отдельных кубиков. При попадании пули один кубик удаляется из структуры фигуры. Если кубиков не осталось, фигура уничтожается полностью.

`field.py` хранит закреплённые кубики в матрице игрового поля. Когда фигура больше не может опускаться, её оставшиеся кубики фиксируются. После этого проверяются полностью заполненные горизонтальные линии: они удаляются, а свободные строки добавляются сверху.

`player.py` реализует управление пушкой с помощью клавиш клавиатуры. `bullet.py` отвечает за движение пуль вверх и их взаимодействие с падающими фигурами.

`ui.py` отвечает за отображение игрового интерфейса, счёта и экрана проигрыша. `constants.py` содержит основные настройки игры: размеры окна, игрового поля и цвета.

**Результат:** реализована базовая версия игры с падающими фигурами, управлением пушкой, стрельбой, проверкой столкновений, закреплением кубиков и очисткой заполненных линий.

## Лабораторная работа №2 — Конфигурация фигур и журналирование

Вторая лабораторная работа посвящена работе с файлами и представлению данных в Python.

### Конфигурация фигур

`shapes.cfg` содержит текстовые маски геометрии фигур. Каждая фигура обозначается именем в квадратных скобках, после которого указываются строки маски. Символ `1` обозначает наличие кубика, а `0` — пустую ячейку.

Пример конфигурации:

```text
[T]
111
010

[Square]
11
11
```

`shapes_loader.py` реализует загрузку конфигурации при запуске игры. Парсер последовательно считывает строки файла, определяет названия фигур, проверяет корректность масок и преобразует их в списки координат кубиков.

Проверяется наличие имени и маски, одинаковая длина строк, допустимость символов `0` и `1`, отсутствие пустых фигур и повторяющихся имён. При обнаружении некорректной структуры возникает ошибка с описанием проблемы.

Благодаря внешнему файлу конфигурации геометрию фигур можно изменять без редактирования основного игрового кода.

### Журналирование событий

`defense_logger.py` отвечает за журналирование событий очистки линий. Для записи используется стандартный модуль `logging`.

При удалении каждой заполненной линии в журнал заносится дата, время и индекс строки.

`defense.log` хранит записи о событиях очистки линий. Новые записи добавляются в конец файла, поэтому предыдущая история сохраняется между запусками игры.

**Результат:** реализована загрузка игровых фигур из внешнего файла, проверка корректности конфигурации и запись важных игровых событий в журнал.

## Лабораторная работа №3 — Telegram-бот и игровая аналитика

Третья лабораторная работа посвящена созданию Telegram-бота для взаимодействия с игровой статистикой и результатами игроков.

Создан Telegram-бот **«Оборонный Штаб»**, который позволяет получать информацию об игровых результатах, просматривать рейтинг и достижения.

### Основные модули

`bot.py` — основной модуль Telegram-бота. Он обрабатывает команды и сообщения пользователей, запускает необходимые функции и обеспечивает взаимодействие с меню.

`config.py` содержит настройки приложения и данные для подключения Telegram-бота.

`keyboards.py` отвечает за создание клавиатур и кнопок главного меню.

`analytics.py` реализует обработку игровой статистики. Модуль загружает данные из `shapes.cfg`, анализирует события из `defense.log`, работает с таблицей рекордов и формирует статистические результаты.

`session.py` отвечает за сохранение и восстановление пользовательских сессий. Данные пользователей хранятся в формате JSON в папке `sessions/`.

### Возможности бота

- Запуск бота и отображение главного меню.
- Получение справочной информации.
- Просмотр рейтинга лучших игроков.
- Просмотр общей игровой статистики.
- Получение списка достижений.
- Импорт CSV-файлов.
- Проверка корректности импортируемых данных.
- Сохранение и восстановление пользовательских сессий.

### Игровая статистика

Для хранения результатов используется файл `leaderboard.csv`.

В таблице сохраняются следующие данные:

| Поле | Описание |
|---|---|
| `player_name` | Имя игрока |
| `lines_cleared` | Количество уничтоженных линий |
| `score` | Набранные очки |
| `games_played` | Количество сыгранных игр |

Система аналитики позволяет получать рейтинг игроков, подсчитывать количество игр, уничтоженных линий и набранных очков.

### Система достижений

В боте реализованы достижения, зависящие от количества уничтоженных линий:

- 🥉 10 линий — первое достижение.
- 🥈 50 линий — второе достижение.
- 🥇 100 линий — третье достижение.

Для создания бота используется библиотека `aiogram`. Асинхронная обработка реализована с помощью `asyncio`, а управление последовательностью действий пользователя — с помощью FSM.

**Результат:** разработан Telegram-бот, позволяющий взаимодействовать с игровой статистикой, просматривать рейтинг, получать достижения и импортировать результаты из CSV-файлов.

## Лабораторная работа №4 — Реализация игровой логики на JavaScript

Четвёртая лабораторная работа посвящена переносу основных алгоритмов игры на JavaScript и реализации объектно-ориентированной структуры программы.

В ходе работы игровая логика была разделена на отдельные модули, каждый из которых отвечает за определённую часть игрового процесса.

### Основные модули

`game-field.js` содержит класс `GameField`, который реализует игровое поле в виде матрицы. Модуль отвечает за проверку занятости ячеек, закрепление кубиков и очистку заполненных горизонтальных линий.

`shapes-loader.js` отвечает за загрузку конфигурации фигур и преобразование масок в координаты отдельных кубиков.

`falling-shape.js` содержит класс `FallingShape`, который реализует создание и движение падающих фигур, проверку возможности перемещения и обработку столкновений.

`cannon.js` содержит класс `Cannon`, отвечающий за положение и перемещение пушки.

`bullet.js` реализует объект пули и проверку её взаимодействия с кубиками падающей фигуры.

`main.js` объединяет основные модули и демонстрирует их совместную работу.

### Проверка алгоритмов

Для проверки корректности реализации созданы отдельные тестовые файлы:

- `test-field.js` — проверка создания матрицы и работы игрового поля.
- `test-cannon.js` — проверка положения и движения пушки.
- `test-collision.js` — проверка столкновений фигур с границами поля и пулями.
- `test-lines.js` — проверка заполнения и удаления горизонтальных линий.
- `test-integration.js` — проверка совместной работы игровых компонентов.

Для запуска тестов используется Node.js.

Пример запуска:

```bash
node test-field.js
node test-cannon.js
node test-collision.js
node test-lines.js
node test-integration.js
```

В ходе тестирования проверена возможность закрепления кубиков, обнаружения заполненной линии и её удаления. Также проверяется корректность перемещения фигур и взаимодействия пуль с игровыми объектами.

**Результат:** реализованы основные игровые классы и алгоритмы на JavaScript, выполнено модульное и интеграционное тестирование. Графический интерфейс в рамках этой работы не создавался.

## Лабораторная работа №5 — Веб-виджет с использованием JavaScript

Пятая лабораторная работа посвящена созданию браузерной версии игры с использованием HTML5 Canvas и JavaScript.

Для отображения игрового процесса используется HTML-страница `index.html`, а основная игровая логика находится в файле `game.js`.

### Основные компоненты

`index.html` содержит структуру страницы, игровое поле Canvas, отображение счёта, кнопки управления и инструкцию для игрока.

`game.js` отвечает за игровой процесс: создание фигур, движение пушки, создание пуль, обработку столкновений, закрепление кубиков и очистку заполненных линий.

Для обновления игрового состояния используется `requestAnimationFrame`, обеспечивающий непрерывный игровой цикл и плавную анимацию.

### Управление игрой

- `A` / `D` — перемещение пушки влево и вправо.
- `Space` — выстрел.
- Клик мышью по игровому полю — выстрел.
- `P` — постановка игры на паузу.
- Кнопка «Пауза» — остановка игрового процесса.
- Кнопка «Продолжить» — возобновление игры.
- Кнопка «Начать заново» — перезапуск игры.
- `R` — перезапуск после проигрыша.

### Реализованная механика

- Игровое поле отображается на HTML5 Canvas.
- Пушка управляется с помощью клавиш `A` и `D`.
- Пули создаются при нажатии Space или клике мышью.
- Пули движутся вверх с заданной скоростью.
- При пересечении координат пули и кубика вызывается функция разрушения кубика.
- Уничтожаются только кубики текущей падающей фигуры.
- Закреплённые кубики нельзя уничтожить выстрелами.
- Фигуры плавно опускаются сверху вниз.
- При достижении препятствия или нижней границы фигура закрепляется на игровом поле.
- Полностью заполненные горизонтальные линии удаляются.
- За уничтожение кубиков и очистку линий начисляются очки.
- При невозможности создать новую фигуру игра завершается.
- Реализованы пауза и перезапуск игрового процесса.

Для проверки столкновений используется сравнение координат прямоугольных областей игровых объектов. Скорость движения и падения рассчитывается с учётом времени между кадрами.

**Результат:** создан работающий браузерный игровой виджет с использованием HTML5 Canvas, JavaScript и `requestAnimationFrame`. Реализованы управление, стрельба, плавное падение фигур, столкновения, начисление очков, пауза и перезапуск.

## Быстрый старт

### Требования

Для работы всех частей проекта используются:

- Python 3.12;
- Pygame 2.6.1;
- aiogram 3;
- Node.js;
- современный браузер с поддержкой HTML5 Canvas и JavaScript.

### Установка проекта

Клонируйте репозиторий:

```bash
git clone https://github.com/meymorgentau/Tetris-Defense.git
cd Tetris-Defense
```

### Запуск Python-игры

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его:

```bash
.venv\Scripts\activate
```

Установите Pygame:

```bash
python -m pip install pygame==2.6.1
```

Запустите игру:

```bash
python Tetris_Defense.py
```

Перед запуском необходимо убедиться, что файлы `shapes.cfg` и `shapes_loader.py` находятся в папке проекта вместе с остальными игровыми модулями.

### Запуск Telegram-бота

Перейдите в папку бота:

```bash
cd py_bot
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Укажите токен Telegram-бота в настройках окружения и запустите:

```bash
python bot.py
```

### Запуск JavaScript-модулей

Для выполнения тестов ЛР4 необходим Node.js.

Проверить его установку можно командой:

```bash
node --version
```

Перейдите в корневую папку проекта и запустите тесты:

```bash
node test-field.js
node test-cannon.js
node test-collision.js
node test-lines.js
node test-integration.js
```

### Запуск браузерной игры

Для запуска ЛР5 откройте файл `index.html` в современном браузере.

После открытия страницы появится игровое поле, пушка, счёт и кнопки управления. Дополнительная установка библиотек для браузерной версии не требуется.

## Игровая механика

- **Падение фигур:** фигуры автоматически опускаются сверху вниз.
- **Стрельба:** пули движутся вверх и уничтожают отдельные кубики падающих фигур.
- **Закрепление:** оставшиеся кубики фиксируются на игровом поле.
- **Очистка линий:** заполненные горизонтальные линии удаляются.
- **Начисление очков:** за игровые действия начисляются очки.
- **Увеличение сложности:** скорость падения фигур постепенно увеличивается.
- **Внешняя конфигурация:** геометрия фигур хранится в `shapes.cfg`.
- **Проверка конфигурации:** загрузчик проверяет корректность масок фигур.
- **Журналирование:** информация об уничтоженных линиях записывается в `defense.log`.
- **Игровая аналитика:** Telegram-бот предоставляет доступ к рейтингу и статистике.
- **Пользовательские сессии:** данные взаимодействия с ботом сохраняются в JSON.
- **JavaScript-модули:** основные алгоритмы игры реализованы в отдельных классах.
- **Тестирование:** работа JavaScript-модулей проверяется отдельными тестами.
- **Браузерная версия:** игровой процесс реализован на HTML5 Canvas.
- **Игровой цикл:** обновление и отрисовка выполняются с помощью `requestAnimationFrame`.
